## Descripción del Problema
Este programa en Python resuelve el cálculo del promedio final de un estudiante a partir de tres notas ingresadas.

Se define la función `calcular_promedio(nota1, nota2, nota3)`, la cual recibe tres valores numéricos como parámetros, calcula la media aritmética dentro de su bloque interno y retorna el resultado para ser impreso en la consola desde el bloque principal (`if __name__ == "__main__":`).
